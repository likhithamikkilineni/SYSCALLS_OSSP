## 2. Implement `ls -l | grep ".c"`

### Aim

To implement the shell command `ls -l | grep ".c"` using system calls.

### System Calls

* `fork()` – Creates processes.
* `pipe()` – Connects the processes.
* `dup2()` – Redirects input/output.
* `exec()` – Executes `ls` and `grep`.
* `wait()` – Waits for child processes.

### Flow

```text
ls -l → PIPE → grep ".c" → Output
```

### Easy Memory

```text
fork() → Create
pipe() → Connect
dup2() → Redirect
exec() → Execute
wait() → Wait
```

## Conclusion

Pipes allow processes to communicate, while `fork()`, `dup2()`, and `exec()` are used to implement shell pipelines.
