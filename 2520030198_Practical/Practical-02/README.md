# Practical-02: File Copy Using Linux System Calls

## Aim : 
To develop a C program that copies the contents of one file to another using the Linux system calls open(), read(), write(), and close(). Also, to understand how control moves between user space and kernel space and analyze the system calls generated by cat sample.txt using strace.

## Problem Statement

1. Develop a C program that uses the system calls open(), read(), write(), and close() to copy the contents of one file to another.
2. Explain how control transitions between user space and kernel space during execution.
3. Use the strace utility to trace all system calls generated by the command cat sample.txt.
4. Analyze the sequence of system calls and identify the kernel services involved.

## Process

* Create a source file containing sample data.
* Open the source file using open().
* Create and open the destination file using open().
* Read data from the source file using read().
* Write the data into the destination file using write().
* Close both files using close().
* Execute strace cat sample.txt to observe the system calls.
* Analyze the system calls used during execution.

## System Calls Used

* `open()` – Opens or creates a file.
* `read()` – Reads data from a file.
* `write()` – Writes data to a file.
* `close()` – Closes the opened file.
* `strace` – Displays the system calls made by a program.

## Compilation and Execution

Step 1: Compile the Program

gcc filename.c

 Step 2: Run the Program
 
./a.out

 Step 3: Trace System Calls

strace cat sample.txt
