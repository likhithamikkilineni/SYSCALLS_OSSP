Main Loop: int main() is the starting point of the C program.
Display Prompt: printf() is used to display the prompt to the user.
Read User Input: scanf() or read() is used to take input from the user.
Handle Exit Conditions: if, else, and break are used to stop the program when the exit condition is met.
Control Flow Diagram: A flowchart is designed to show the sequence of program execution.
Test Interactive Loop: The program is executed repeatedly with different inputs to check its working.
Capture Keyboard Input: scanf() or read() captures the characters entered through the keyboard.
Handle Backspace: Backspace can be handled by processing keyboard input character by character.
Process Enter Key: The Enter key is identified using the newline character '\n'.
Manage Input Buffer: A character array such as char buf[100] is used to store the user input.
Multi-Character Commands: A character array/string such as char command[100] is used to store multiple characters or commands.
Test User Interaction: Different commands and inputs are given to verify that the program responds correctly.
